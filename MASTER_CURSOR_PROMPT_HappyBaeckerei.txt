MASTER CURSOR PROMPT — Happy Bäckerei (Next.js + TS + Tailwind + Supabase)

- Amaç: “Happy Bäckerei” için kurumsal vitrin + ürün kataloğu + admin paneli. Kod modüler, okunaklı, test edilebilir. TSX sayfalar kompozisyon-only ve kısa. Deploy: GitHub → Vercel. Veri: Supabase (Postgres + Auth + Storage, free tier).

1) Teknoloji Yığını
- Next.js (App Router) + TypeScript
- Tailwind CSS, shadcn/ui, lucide-react
- Prisma ORM (postgresql)
- Supabase: Postgres + Auth (email + magic link), Storage
- Form: react-hook-form + zod
- i18n: next-intl (varsayılan de-CH, ikincil tr)
- Log/Hata: Vercel Analytics (+ Sentry opsiyon)
- Test: Vitest + Testing Library + Playwright (E2E)
- Kalite: ESLint + Prettier + Husky + lint-staged
- Harita: Leaflet + OpenStreetMap
- SEO: Metadata, OG, sitemap, robots

3) “Kısa TSX” Kuralları (zorunlu)
- Sayfalar: yalnız kompozisyon, ≤ 40–60 satır.
  - Read: features/*/queries.ts
  - Write: features/*/actions.ts (server actions)
  - Mantık/RBAC/mapping: service ve mappers
- UI parçala: grid/card/filter/modal ayrı bileşenler.
- Import sınırı: sayfalardan '@/lib/db' doğrudan import yok.

Örnek kısa sayfa:

// app/(shop)/products/page.tsx
import { getProducts } from "@/features/products/queries";
import { ProductGrid } from "@/components/feature/products/ProductGrid";

export default async function ProductsPage() {
  const items = await getProducts();
  return <ProductGrid items={items} />;
}

4) Prisma Şeması (çekirdek)

datasource db { provider = "postgresql"; url = env("DATABASE_URL") }
generator client { provider = "prisma-client-js" }

model User {
  id        String   @id @default(cuid())
  email     String   @unique
  name      String?
  role      Role     @default(STAFF)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  AuditLogs AuditLog[]
  Orders    Order[]
}

enum Role { ADMIN MANAGER STAFF VIEWER }

model Category {
  id       String    @id @default(cuid())
  slug     String    @unique
  name_de  String
  name_tr  String?
  sort     Int       @default(0)
  products Product[]
}

model Product {
  id             String   @id @default(cuid())
  categoryId     String
  category       Category  @relation(fields: [categoryId], references: [id])
  slug           String    @unique
  name_de        String
  name_tr        String?
  description_de String?
  description_tr String?
  price_chf      Decimal   @db.Decimal(10,2)
  tax_rate       Decimal   @default(0.0) @db.Decimal(4,1)
  active         Boolean   @default(true)
  image_url      String?
  badges         String[]
  createdAt      DateTime  @default(now())
  updatedAt      DateTime  @updatedAt
}

model Order {
  id        String   @id @default(cuid())
  userId    String?
  user      User?    @relation(fields: [userId], references: [id])
  items     Json
  total_chf Decimal  @db.Decimal(10,2)
  status    String   @default("pending")
  createdAt DateTime @default(now())
}

model AuditLog {
  id        String   @id @default(cuid())
  actorId   String?
  actor     User?    @relation(fields: [actorId], references: [id])
  action    String
  entity    String
  entityId  String
  diff      Json
  createdAt DateTime @default(now())
}

5) Admin Modülü (RBAC + CRUD)
- RBAC: ADMIN, MANAGER → CRUD; STAFF → view-only; VIEWER → sınırlı görünüm.
- Ürün/Kategori: liste, ara/filtre, oluştur/düzenle/sil, drag‑drop upload → Supabase Storage (mime/size kontrol).
- CSV/Excel import/export (fiyat ve kütlesel güncelleme).
- Soft-delete + versiyonlama (flag + AuditLog).

6) Güvenlik & Uyum
- Auth: Supabase Auth (email + magic link), 2FA/TOTP opsiyonel.
- Rate limit, CSRF, bot koruması (Cloudflare Turnstile).
- Yasal: Impressum, Datenschutzerklärung (DSG/DSGVO).
- Ürün detay: alerjen/içerik alanları.
- MWST: gıda için indirimli oranlar (nihai oranlar Treuhand ile teyit).

7) Performans, Erişilebilirlik, i18n
- Lighthouse: Perf ≥ 85, A11y ≥ 95.
- Görseller: Next/Image, webp türev, sabit aspect-ratio, lazy.
- Erişilebilirlik: klavye navigasyonu, ARIA, kontrast ≥ 4.5:1.
- i18n: next-intl de‑CH varsayılan, tr anahtarlar hazır.

8) PWA (opsiyonel, “lite”)
- Shell + kritik görseller cache; offline sepet yok.
- Minimal manifest.json + service worker.

9) CI/CD, Test, Yedekleme
- GitHub Actions: typecheck + lint + test + build.
- Playwright E2E: login, ürün liste, admin CRUD smoke.
- Sentry entegrasyonu (ops.).
- DB snapshot günlük; Storage versiyonlama (Supabase).
- Ortamlar: dev / staging / prod.
